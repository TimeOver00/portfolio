# Portfolio — Ahmed Zaned

Développeur Full Stack C# / .NET & Angular — DevOps.

Site personnel présentant mon profil, mon expérience, mes projets et mes compétences. Construit avec React, Vite et TypeScript, avec quelques animations (Framer Motion) et un thème clair/sombre.

🔗 [ahmedzaned123@gmail.com](mailto:ahmedzaned123@gmail.com) · [linkedin.com/in/ahmed-zaned](https://linkedin.com/in/ahmed-zaned)

## Stack

- React + TypeScript + Vite
- Framer Motion (animations)
- CSS avec variables pour le thème clair/sombre

## Lancer le projet

```bash
npm install
npm run dev
```

```bash
npm run build   # build de production dans dist/
```

## Structure

Le contenu (profil, expérience, projets, compétences, formation) est centralisé dans [src/data.ts](src/data.ts), séparé des composants d'affichage dans [src/components](src/components).
